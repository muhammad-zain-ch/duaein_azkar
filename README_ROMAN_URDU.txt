AZKAR & DUAIN - Android Studio Project

Is project mein aapki 32 pages wali PDF app ke andar bundled hai. Install hone ke baad PDF dekhne ke liye internet ya alag PDF reader ki zaroorat nahi.

APK banane ka tareeqa:
1. Android Studio install karein.
2. Is ZIP ko extract karein.
3. Android Studio mein extracted AzkarDuain folder open karein.
4. Gradle sync complete hone dein (pehli baar internet lag sakta hai taake Android build dependencies download hon).
5. Menu: Build > Build Bundle(s) / APK(s) > Build APK(s).
6. APK yahan milegi: app/build/outputs/apk/debug/app-debug.apk
7. APK ko apne Android phone par bhej kar install karein. Agar phone poochay, is source se install ki permission dein.

App details:
- App drawer label: Azkar & Duain
- Offline PDF included inside the app
- 32 pages, scroll karke parhein
- Minimum Android: Android 6.0 (API 23)
- App internet permission request nahi karti

Note: Is workspace mein Android SDK/Gradle build tools maujood nahi thay, is liye yahan se installable APK compile nahi ho saki. ZIP Android Studio project hai jise APK mein build kiya ja sakta hai.
